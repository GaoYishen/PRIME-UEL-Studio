# PRIME UEL Studio 使用手册

## 1. 当前版本能做什么

当前版本用于模型和文件准备。它可以从 Abaqus/CAE 菜单打开桌面窗口，读取当前模型、零件、装配实例、分析步、作业和视口，登记模型文件，编辑已声明的参数，生成新的输入副本，执行已登记的检查，并把已有 ODB 交给 Abaqus/Viewer。

PRIME Core 的 UEL、材料本构、私有初态算法和生产模型由本机授权适配器提供。公开包里的弹簧示例只用于演示操作流程。

## 2. 安装 Abaqus/CAE 菜单入口

在公开包根目录运行：

```powershell
py -3 tools/install_abaqus_plugin.py
```

安装后重启 Abaqus/CAE。在 `Plug-ins` 菜单中选择 `PRIME UEL Studio...`。

插件会读取当前 CAE 会话信息，再打开 Studio 窗口。执行反应界面点选操作时，CAE 会把当前模型写入独立的临时 INP 副本，原模型文件保持原样。

## 3. 第一次使用演示模型

1. 双击 `Launch PRIME UEL Studio.cmd`。
2. 选择弹簧参考配置。
3. 在参数页修改刚度、初始位移、终点位移、时间和输出步数。
4. 点击“计算初始状态”。
5. 点击“生成新算例”。
6. 在“计算任务”页选择完整流程，或分别选择只编译、只运行。
7. 计算完成后，在“结果查看”页打开演示曲线。

这个流程只验证界面、参数绑定、文件副本和任务回执。

## 4. 接入本机 UEL 模型

在“模型与文件”页登记模型父目录、Fortran 源文件、INP 文件和外接文件。登记动作只保存相对路径和 SHA-256，不修改原模型。

随后需要由模型配置卡声明：

- 参数名称、单位、默认值和范围
- 每个参数写入的新副本文件和唯一 token
- 初始状态适配器
- 编译、输入检查和运行步骤
- 结果文件和判据

没有这些声明时，Studio 只能完成文件身份核对，不能猜测材料、初态或 UEL 连接方式。

## 5. 反应界面单元如何插入

这个功能的稳定实现路径是“CAE 选择，拓扑提取，复制 INP 生成，Abaqus 检查”。当前版本已经接通二维 T3 反应边和三维 H8 反应面拓扑生成。

### 5.1 用户操作

1. 在 CAE 中打开目标模型，或直接准备一个显式二维 INP。
2. 在 CAE 的 `Plug-ins → PRIME UEL Studio` 子菜单中选择对应的 T3 反应边或 H8 反应面操作。
3. 在当前视口先点选固相单元，点击 Done，再点选液相单元并点击 Done。Studio 会自动导出当前模型的 INP 副本，并分别带入两相单元标签。
4. Studio 只识别固相—液相之间的相邻公共边或公共面，一次生成多个界面单元。
5. 也可以从 Studio 的“模型与文件”页打开生成窗口，分别输入固相和液相的逗号分隔单元标签。
6. 填写授权适配器规定的界面 UEL 类型，例如 `U2`。
7. 点击“生成新副本”。原始 INP 保持不变。
8. 查看 `interface_manifest.json` 中的公共边、相反节点、法向和哈希。
9. 由私有适配器补充属性卡、DOF 合同和执行配方。
10. 先执行 Abaqus datacheck，再提交短程诊断计算。

H8 操作使用四个公共面节点和左侧父 H8 的四个非面节点，形成八节点界面单元。两侧父单元和面节点顺序会写入清单，私有适配器负责确认实际 UEL 的节点和 DOF 合同。

公开包中的 `examples/interface/multiphase_t3.inp` 提供了一个多单元跨相案例。固相单元为 `101、102`，液相单元为 `201、202`，程序会识别两条公共边并生成 `U2` 界面单元 `203、204`。同目录的 SVG 图解释了从两相选择到界面生成的过程。

### 5.2 程序内部步骤

程序需要完成以下工作：

1. 从 CAE 上下文得到父单元标签、单元类型和节点连接。
2. 找到两个材料域之间的公共边或公共面。
3. 按父单元局部编号恢复界面节点顺序。
4. 计算界面法向，并统一两侧的正负方向。
5. 根据节点策略复用节点或生成一组新节点。
6. 生成界面 UEL 的节点连接、ELSET、材料属性和输出声明。
7. 保存父单元到界面单元的映射、DOF 映射、节点策略和文件哈希。
8. 将这些内容写入新的 INP 和 `interface_manifest.json`。

一个公开的映射记录至少包含：

```json
{
  "interface_version": 1,
  "parent_elements": [101, 102],
  "parent_faces": [{"element": 101, "face": 2}, {"element": 102, "face": 1}],
  "parent_connectivity": [[11, 12, 15], [12, 18, 15]],
  "interface_connectivity": [11, 12, 15, 18],
  "node_policy": "shared",
  "normal": [0.0, 1.0],
  "phase_domains": ["graphite", "siox"],
  "dof_map": {},
  "source_hashes": {}
}
```

私有 UEL 只需要读取公开的连接和配置接口，不需要把残量、切线或材料本构暴露给插件。

### 5.3 插入前必须检查

- 两侧父单元确实共享目标边或面
- 节点顺序没有重复或遗漏
- 界面法向方向一致
- 材料域和界面类型相容
- UEL 节点数与 DOF 数匹配
- 复制节点时没有产生未约束的孤立节点
- 生成的 ELSET、NSET 和界面属性名称唯一
- 原始 INP 哈希与生成前记录一致

## 6. 计算和结果查看

先生成新副本，再进行输入检查。输入检查通过后再提交短程计算。计算状态、日志、DAT、STA 和回执由 Studio 保存。ODB 结果使用 Abaqus/Viewer 查看。

Studio 负责准备和交接。云图和自定义 UEL 场量能否显示，取决于 UEL 是否把对应变量写入 ODB，以及输入文件是否声明了正确的输出请求。

## 7. 常见状态

`文件已登记` 表示路径和哈希通过。

`参数已修改` 表示旧初态或旧检查不能继续复用。

`副本已生成` 表示新文件写入并读回检查完成。

`输入检查通过` 表示 Abaqus 输入检查和已声明判据通过。

`计算完成` 表示本次任务产生了可读取的结果文件，不替代物理资格判断。

## 8. 当前功能缺口

固相—液相批量界面拓扑生成已经接通。复制节点策略、复杂曲面和私有 PRIME 属性适配仍需要单独验证。批量生成后应先通过拓扑检查和 Abaqus datacheck，再接入你的私有 PRIME Core。
